# Angular sample

Angular 22 (standalone), using the adapter `@fink-ui/angular`.

```bash
pnpm start   # ng serve on http://localhost:4200
```

## How the library is included

1. **Dependency:** `package.json` lists `@fink-ui/angular` only (plus the Angular packages). `@fink-ui/components`, KoliBri and the theme come with the adapter.
2. **Stylesheet:** `angular.json` adds the document stylesheet under `styles`. Angular bundles its fonts and icons:

   ```json
   "styles": ["node_modules/@fink-ui/angular/fink.css"]
   ```

3. **Registration:** `src/main.ts` calls `defineCustomElements` once before `bootstrapApplication`:

   ```ts
   import { defineCustomElements } from '@fink-ui/angular';

   await defineCustomElements();
   await bootstrapApplication(App);
   ```

4. **Usage:** `src/app/app.ts` puts the components from `@fink-ui/angular` into the `imports` of the standalone component: `FinkPageHeader` and `FinkTaskList` (own) and `FinkAlert` (KoliBri). KoliBri components use their fink-* selector in templates as well (`<fink-alert>`), generated by `scripts/kolibri-angular.mjs`. Objects such as `_on` are bound with `[_on]`, events with `(finkTaskSelect)`.
5. **Build:** `angular.json` sets `"loader": { ".map": "empty" }`; otherwise the glob import of the library loader also picks up its source maps.
6. **Dev server:** `angular.json` sets `"prebundle": false` for `ng serve`. With prebundling, the dev server resolves the adapter's dependencies (e.g. `@public-ui/components`) from the app, which pnpm does not allow because the app depends on the adapter only.
